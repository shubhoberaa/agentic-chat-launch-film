# Treatment — One request, coordinated

## Inventory and concept

Agentic Chat is a chat interface for delegating multi-step work to agents and tools. Unlike a simple prompt-and-reply chat, the request can fan out into coordinated web research, comparison, and a Slack action.

- **Before / after:** several manual steps → one request, returned as a posted result.
- **Specific behavior:** the visible request routes into independent Search, Compare, and Slack steps; the result rejoins as one completed response.
- **Lens finalists:** (a) make routing literal with a prompt branching into task paths; (b) show a backlog collapsing into one finished card; (c) keep one request card in frame as its state changes. Choose (a)+(c): the real request card stays the story object, while a single blue route line shows work splitting and resolving.
- **Logline:** One request routes through three tasks, resolves, then folds into the Agentic Chat mark.
- **Ownership / muted / specificity:** the composer, task states, and product mark belong to this interface; a muted viewer can follow one request through three completed actions; a simple chat reply would not show the parallel task routing.
- **Deletion test:** remove the route and task states and the distinctive value disappears; those are the proof, not decoration.
